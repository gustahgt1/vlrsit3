# VLR LAB

Dashboard fan-made inspirado no universo competitivo de VALORANT.

## Recursos
- Dashboard inicial
- Cards de Overall
- Database de jogadores
- Busca por jogador, função ou rank
- Roleta de jogador, agente, arma, mapa e desafio
- Ranking geral
- Central de estatísticas
- Comparação rápida entre jogadores
- Layout responsivo para celular e PC

## Como usar
Abra `index.html` no navegador. O projeto não precisa de servidor ou banco de dados para funcionar na versão demo.

## Personalização
Os jogadores e estatísticas estão no arquivo `app.js`, no array `players`.

## Observação
Projeto independente/fan-made. Os dados exibidos são demonstrativos e fictícios. Não é afiliado à Riot Games ou VALORANT.
